## Tracks

A line with a label is a track: it gets a strip in the mixer and you hear it.
A line without one builds its modules and stays silent, ready to use
elsewhere.

```js
const seq = $`c2 ~ eb2 g2`
bass: $saw(seq).lpf('c4')
_lead: $sine('c5')
```

| Write                | Means                                          |
| -------------------- | ---------------------------------------------- |
| `bass:`              | a track called bass                            |
| `lead_synth:`        | a track the mixer shows as "lead synth"        |
| `_bass:`             | muted                                          |
| `S_bass:`            | soloed                                         |
| `S__bass:`           | muted and soloed: solo wins                    |
| `bass$2:`            | plays on outputs 2 and 3                       |
| `bass$2m:`           | plays in mono on output 2                      |
| `kick$drums:`        | plays into the group track `drums`             |
| a line with no label | builds modules for other lines to use, unheard |

A track's name works like a `const` in the rest of the patch, so later lines
can read it.

## Updating

<Key command="shoreline.updatePatch" /> runs the patch and plays it, and
<Key command="shoreline.stop" /> stops. Edit and update as often as you like:
modules you kept carry on where they were, so phases, envelopes and sequences
don't restart.

To land a change on the beat, press <Key command="shoreline.updatePatchNextBeat" />: the update waits for the next
beat. <Key command="shoreline.cancelQueuedUpdate" /> cancels an update that is
still waiting.

## Where things are

| Where           | Has                                                               |
| --------------- | ----------------------------------------------------------------- |
| Explorer        | the patches in your workspace folder, and the files you have open |
| Control         | the sliders and buttons your patch declares                       |
| Mixer           | a strip per track, with its level, pan and meter                  |
| Docs            | this guide, and every module and global                           |
| Command palette | every command and its shortcut                                    |

<Key command="shoreline.openWorkspace" /> opens a folder as your workspace,
<Key command="shoreline.save" /> saves, <Key command="shoreline.toggleMixer" />
shows the mixer and <Key command="shoreline.showCommandPalette" /> opens the
command palette.
